# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。

## 可归责拆分（调度限电 / 设备削峰 / 待查）

每个事件切片区分两个上限：设备交流额定容量（逆变器固有）与并网点调度功率上限（来自上限依据，按设备+半开时间窗[start,end)命中采样时刻，无窗口时回落到额定容量）。基线拟合额外输出未被本机额定截断的应发潜力 `potential_kw`，`baseline_kw=min(potential, 额定)`。三段互斥、同一缺额只归因一次：

- 设备削峰 `clipping_kwh` = max(potential − min(potential, 额定), 0)×时长。源于应发潜力超出交流额定容量，与调度无关，不可申报。
- 可申报损失 `dispatch_kwh` = max(min(potential, 额定) − 采用上限, 0)×时长，采用上限=min(调度上限, 额定)。调度把并网点压到可达基线以下的部分才可向调度申报。
- 待查 `pending_kwh` = max(采用上限 − 实际, 0)×时长。实际未达到采用上限，无法证明由限电导致，列入待查，不申报。
- 实际功率高于采用上限时依据与遥测自相矛盾，该段调度缺额清零、原损失整段转待查。
- 恒等关系：dispatch+clipping+pending = max(potential−实际,0)×时长；dispatch+pending = 原损失 loss_kwh。无基线片段（缺测/故障/无合格对照）三字段保持null、归责码NO_BASELINE，不填0。

仅当行/时间/能量/归责四类守恒全部通过且无隔离、无未定、无待查片段时方可封存。上限依据切换只重算设备窗口发生变化的切片，未受牵连时段逐字段保留；切换在单事务内完成，中断整体回滚到旧版，已上传的依据原始字节只增不删，同依据重试幂等（不新增审计、不改凭据）。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。
